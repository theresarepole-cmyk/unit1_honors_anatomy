NETLIFY DEPLOYMENT

1. Unzip this folder if needed.
2. Go to Netlify and use Add new site > Deploy manually.
3. Drag the entire 'unit1-anatomy-netlify' folder into the deploy area.
4. Netlify will publish index.html automatically.

This site is self-contained:
- No external JavaScript libraries
- No external CSS files
- No image files required
- All navigation uses normal anchor links
